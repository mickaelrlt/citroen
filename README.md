# Citroen

Crée moi une application, aussi bien sur ordinateur que mobile :  
Je suis vendeur automobile chez citroen, Je veux plusieurs catégorie ;
-Compartiment client offre ; Entrer son nom prénom et ses coordonnée , possibilité de mettre une note (ex: client indécis pour une C3), mettre l'offre proposé a ce client ( LOA / LLD/ COMPTANT) la reprise de sa voiture et le montant et possibilité de mettre un rappel calendaire avec une notification pour par exemple le relancer a telle date avec la raison
-Compartiment client commande ; Véhicule neuf ou occasion, le modèle de voiture avec l'immatriculation et le numéro de chassis, la date prévu de livraisons, possibilité de mettre un rappel calendaire (ex: appeler pour signer un financement), pouvoir mettre des statuts différents (papiers non recu/papier OK, financement en attente d'accord, en attente de livraisons) mettre si LOA/LLD/COMPTANT
-Compartiments véhicule de direction ; pouvoir mettre les véhicule de direction disponible (Chassis, immatriculation, Modèle, Finition, Option, Prix)
